# 速度拾取本地试用版（2026-10-29）

在频谱 r6 的基础上增加实际速度拾取功能。入口为 `Tools → Velocity Picking`，或主图左侧 FK 下方的蓝色曲线按钮（按钮 24×24、图标 20×20）。速度窗口是独立非模态窗口；拾取和曲线均在主窗口地震底图上完成。

## 三栏布局

- 第一栏：Mode、Display。选择直线/双曲线、距离来源、排列划分、道间距，调节当前曲线颜色和线宽，显示/隐藏全部曲线，开始/停止拾取。
- 第二栏：Pick Points、Result、CSV。显示两点距离和时间、道号、计算速度和 t0，支持取消当前草稿、导入多个 CSV、导出当前文件的速度列表。
- 第三栏：Picks。复用 `MyStringTable`，沿用项目灰色表头、细网格、单行选择；点击 `t0 (ms)` 表头按数值升序/降序。选择一行会在主图以橙色描边和临时加粗高亮对应曲线，可查看结果并更改该曲线颜色/线宽；支持删除和撤销。高亮不改写记录本身的显示参数。

## 操作

1. 在主界面打开 SEG-Y，调整至需要的显示范围，再打开速度窗口。
2. 选择 Line 或 Hyperbola，确认 Distance 和 Gather by。首次读取道头在后台进行，底部显示进度。
3. 在主图左键第一次点击固定 P1，移动鼠标预览，再左键点击确定 P2；立即计算和保存，无 RUN 按钮。
4. 曲线使用每一道自身的距离延伸到同一文件内各排列；排列边界断开，不连接相邻排列的尾、首道。改变显示范围、方向或缩放后仍按数据坐标绘制。
5. 有草稿时右键或 Esc 取消草稿；没有草稿时右键或 Esc 停止拾取。`Ctrl+Z` 或 Undo 撤销最近的拾取、删除或 CSV 导入。拾取期间暂时锁定主图的缩放、移动和延迟切换；停止拾取即可恢复。
6. 主界面原有截图及高 DPI PNG 导出均保留曲线，仍按原有规则在源文件目录自动命名、同名编号。

切换数据文件时，曲线按源文件指纹分别缓存在本次程序会话内；切回原文件恢复。关闭速度窗口会隐藏主图速度线并停止拾取，记录保留；重新打开窗口会自动显示当前文件的已绘曲线，并打开 Show curves。**退出程序前请 Export CSV 保存；拾取列表不跨程序重启自动保存。** 模式、距离来源、排列划分、间距、颜色、线宽和时间排序保存在 QSettings。

## 距离、排列与公式

坐标距离使用 SEG-Y 第 73/77 字节的炮点坐标与第 81/85 字节的检波点坐标之差的模，应用第 71 字节坐标标量，以及二进制头第 55 字节的米/英尺单位。正标量乘、负标量除、零按 1。经纬度等角度坐标不直接当米，改选 Offset 或 Trace spacing。

Offset 使用第 37 字节的有符号炮检距；Trace spacing 按排列内道序号乘 Dx。未声明长度单位时按米并在状态栏提示。SU 没有二进制单位头，按米处理。

Gather by 的 Auto 优先检查 Field record（第 9 字节）变化，其次 Source point（第 17 字节），再检查 Channel（第 13 字节）回到较小或相同正数。候选字段必须同时存在排列边界和多道连续区间；逐道递增的记录号、恒定正数道号造成的全单道分组不会被自动采用。没有可用候选时按单排列显示。可手动指定划分方式，以匹配文件道头。每条已保存曲线保留创建时的距离、间距和排列划分参数。

拟合使用米和秒，界面时间以毫秒显示：

- 直线：`t = t0 + x / v`，两点确定斜率和截距，v 保留方向符号。
- 双曲线：`t² = t0² + x² / v²`，两点求 v 和 t0，不假定第一个点就是顶点。不存在实数解、重复距离或非有限数值会提示原因。

t0 的原点是原始道样点零时刻。主图启用 Use delay 时，拟合先扣除各道第 109 字节的记录延迟，显示时再加回，保持数据与曲线对齐。

## CSV

CSV 必需列为 `t0(ms),velocity(m/s)`；`freq0(Hz),Amp` 等附加列忽略。也支持 `t0(s)`。

Auto 根据 `type`/`mode` 列或文件名中的 line、curve、hyper 判断类型；无法判断时，在 CSV Type 中明确选 Line/Hyperbola 后导入。可以多选文件，任何一个校验失败均不导入本批数据。

导出格式：

```csv
type,t0(ms),velocity(m/s),distance_source,dx(m),gather_by
hyperbola,500,2000,coordinates,25,0
line,100,2000,coordinates,25,0
```

distance_source 为 coordinates/offset/spacing；gather_by 为 0 Auto、1 Field record、2 Source point、3 Channel reset、4 Single gather。额外元数据可在重新导入时保留原有几何解释。导出包含当前文件全部曲线，按当前时间排序，以 QSaveFile 原子写入。

## 本地验证与范围

先用普通 `GxApps.pro` 构建应用与依赖。在应用构建目录对 `SeiSeeMp/SeiSeeMp.pro` 添加 qmake 配置 `CONFIG+=velocity_regression` 可构建速度回归，`CONFIG+=fk_regression` 可构建 FK/频谱回归。测试运行前分别设置 `SEISEE_VELOCITY_TEST_OUT` 或 `SEISEE_TEST_OUT` 指定输出目录。可用 `QT_QPA_PLATFORM=offscreen` 进行离屏验证。

速度回归覆盖两点公式、CSV 格式及无效输入、坐标标量/英尺换算/角度坐标、SEG-Y/SU、排列边界和反向排列、延迟对齐、排序后删除与撤销、文件切换缓存、主图实际鼠标交互、与频谱框选互斥、普通截图/300 DPI 曲线位置一致性、关闭期间后台结果以及目录内被占用文件的识别。

试用版道头读取上限 200 万道；单 CSV 最大 10 MB、当前文件最多 10000 条曲线。不支持 CST 速度拾取。验证主要使用合成多排列数据，真实数据的道头定义仍需在试用时核对。
