# Metrics 修改说明

您好，已根据您这轮反馈调整 Metrics 的交互、计算和报告保存。具体修改如下，供您复核。

## 1. 文件选择

计算模式的 Signal file 固定为打开指标窗口时主窗口中的文件，输入框及对应 Open 按钮置灰；Noisy file 可以通过 Open 或粘贴路径更换。

估算模式默认沿用计算模式已选择的 Noisy file；未选择时，使用打开指标窗口时的文件。估算模式的 Open 保持可用，也支持粘贴路径。两种模式共用 Noisy file 选择，更换后会清空旧结果，并更新全道、全时间范围。

## 2. 估算模式标签

估算模式的输入标签已改为 Noisy file，隐藏第二文件行，避免将输入误认为 Signal file。

## 3. 非模态窗口与关闭处理

指标窗口已改为非模态，便于在主窗口浏览目录、复制路径和打开其他文件。指标窗口独立持有文件读取对象，主窗口切换文件不会释放正在计算的输入。

本次窗口会话的 Signal file 保持固定；关闭指标窗口后重新打开，可从主窗口重新取得 Signal file。主窗口关闭时，会停止指标任务、等待计算线程结束并关闭指标窗口。

## 4. 复用 libCwp FFT

TPRS 的谱计算已改用 libCwp/pfafft.cpp 中的 npfar / pfarc，FFT 输入、频谱和 TPRS 谱运算使用 float，并移除了自行实现的 radix-2 FFT。基础误差指标保留既有累加精度。

目前保留原来不计 Nyquist 的约定。CWP 有效变换长度和单精度可能使 TPRS 与之前略有差异；时间窗超过 CWP 的长度限制时会提示缩短范围。此处保留了后续替换 FFT 后端的入口。

## 5. 统一结果表格

概览表格已改用项目已有的 MyStringTable。单选框、复选框继续复用 CustomRadioButton / CustomCheckBox，未另行修改公共控件。

## 6. 报告信息与默认保存位置

计算报告从第二行开始写入实际使用的 Signal file、Noisy file 路径。估算报告第二行写入 Noisy file，包括仅计算 TPRS 的情况。

保存对话框的默认目录跟随主窗口当前目录浏览区，默认文件名为 `<noisy文件名去扩展名>-metrics.txt`。例如 data.sgy 对应 data-metrics.txt。报告以 UTF-8 保存。

## 验证范围

Windows x64 / Qt 5.15.2 / MSVC 2022 的 Release 构建已通过。100%、125%、150%、200% 四种缩放下，各 7 项测试通过、0 失败（含初始化与清理）；使用便携目录 DLL，且 PATH 仅含 Windows 系统目录时，同样为 7 项通过、0 失败。

测试覆盖文件默认回退、继承与更换、Signal file 固定灰显、主窗口切换文件后继续计算、默认保存目录与文件名、报告中的输入路径、停止状态及计算中关闭主窗口。

数值检查包括相同文件的 MSE=0、SSIM=1，半幅信号的 SNR=6.020599913 dB，以及 CWP float TPRS 对同形相邻道的理论值 1、0.8、0。已检查两种模式的离屏界面图。

本次使用合成 SEG-Y 和离屏 UI。Linux 尚未编译运行，真实大体积数据、所有原生文件对话框及实际跨显示器切换尚未全面验证。TPRS 的科学适用性没有重新论证；估算模式的均值参考分数不能直接解释为真实恢复精度。
