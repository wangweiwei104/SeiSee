# FK / Frequency Spectrum 最终 UI 与多文件对比（2026-10-28）

后续 r5（2026-10-29）已修改单道自动计算、Nyquist 边界、dB 约定、图例与导出；最新行为以 [r5 说明](spectra-r5-20261029.md) 为准。下文为历史实现记录。

r4：主窗口有效选道统一发出 `traceSelectionChanged`（1-based 顺序道号），普通频谱通过 `setMainTrace()` 接收。Single Trace 下即时更新 Trace 首框，不改时间范围、不自动 FFT；Selection 下保留区域参数，切回单道时采用主窗口最近选择。首次打开频谱也采用主窗口已选中的道。计算中的请求使用原参数快照，后续点击只更新下一次输入，不错绑本次谱。

同时修复首次打开的蓝色小矩形：共享选框构造时显式隐藏、清空初始几何；两个窗口关闭时重置选框、拖动和光标，重开不残留未完成的框选。

框选样式 r3：FK 与普通频谱子窗口的框选放大，以及它们触发的主图输入范围框选，统一使用 `GxLib/gfxselectionband.h`：细蓝边框、约 25% 透明度的高亮色填充，参照主窗口 ZoomW。边线为 1 物理像素，内部仍可看见数据；不再受原生 QRubberBand 空心遮罩和窗口失焦颜色影响。主窗口原有 ZoomW 保留为参照。绘制替换不改变选区坐标、调整、取消、松开缩放和视图回退行为。

界面采用两份 Designer XML：三栏 FK UI（含 Advance / FontSize）与五栏普通频谱 UI。Single Trace、Selection、Show Grid 均为勾选框在左、文字在右。

## 最终界面对应

| 区域 | FK 谱 | 普通频谱 |
| --- | --- | --- |
| Mode | 不新增；继续二维 FK 计算 | Single Trace / Selection 两个复选框由 QButtonGroup 保证互斥，且不能同时取消。默认 Single Trace。 |
| Input Range | 道范围、时间范围、dx、当前视图、框选、取消、计算 | 单道模式使用 Trace 首框道号，末道框、全道及区域获取按钮禁用；Selection 使用首末道及时间窗口，支持当前视图、主窗可调整框选。 |
| Display | 波数、频率、色标范围 | 频率、幅度上下限，FontSize、Show Grid。水平/垂直全范围分别恢复频率范围、所有曲线的幅度范围。 |
| Advance | 色表、幅度单位、插值、FontSize | 主曲线颜色、线宽、幅度单位。 |
| Comparison | 无 | 多选添加 SEG-Y；File 下拉框选择当前要设置/删除的文件，Color / Line Width 对该文件单独生效。 |
| 底栏 | 当前文件、显示范围、缓存/计算状态、进度 | 当前文件、已计算道/区域及频率范围、对比文件数量、缓存/计算状态、进度；完整路径及错误详情可悬停查看。 |

- 两个窗口 FontSize 默认均为 **9 pt**，作用于图内标题、坐标和图例；随用户设置持久保存。FK 字号位于 Advance，普通频谱位于 Display。
- 按钮仍为 24×24、图标 20×20 Qt 逻辑像素，继承主程序字体与按钮风格。显示数值有实际的合法边界，未保留参考 XML 的 0 道、0 字号等占位值。
- 普通频谱主线默认 Black，首个对比文件默认 Blue；后续文件分配不同颜色。可选预设颜色或 Custom 自定义颜色，线宽提供 0.5 / 1 / 1.5 / 2 / 3 / 4 / 5 / 6。选择 File 后可分别修改每个对比文件。
- Comparison 增加小型 File 下拉框，是为满足“多个文件分别设置颜色和线宽”；原参考中的打开和删除图标保留。重复添加同一文件会去重；删除选中的对比文件立即移除对应缓存曲线，不重新计算。

## 计算与可比性

1. Single Trace 只对指定的一道、指定时间段计算幅度谱。Selection 对区域内每道分别做 FFT，再对 **FFT 绝对幅度取平均**；不是先平均时域数据再 FFT。
2. 点击计算时固定主文件、模式、道号、时间窗口和文件版本；主文件及所有对比文件按同一参数顺序计算。每个任务复用现有 FkWorker/CWP FFT，并使用独立读文件对象；串行读取限制瞬时原始数据内存。
3. 同一道号指各文件的 **1-based 顺序道号**，不是按 CDP、offset 或其他道头值匹配。时间以原始样点 0 为起点，ms 范围向内对齐样点。
4. 对比文件必须覆盖完整道/时间范围，且采样间隔必须与主文件相同。不自动截短、补零或重采样。不兼容文件会在 Toast 和状态栏 Tooltip 中列出原因，不将该文件的旧结果混入本次曲线。
5. 主文件失败或取消时保留上次完整结果；对比文件失败时显示主文件与其余成功文件，并明确报告失败文件。计算中切换主窗文件不会错绑正在计算的结果。
6. 输入仍为文件原始振幅，不套用主窗 AGC、滤波、归一化或道头延迟。Abs 为未归一化 FFT 幅度，Log10 为 `log10(amplitude + 1e-12)`；不因对比而各自归一化，以保留不同文件的振幅差异。
7. 只有点击计算启动 FFT。模式、选区、文件列表修改后需要再次点击计算；颜色、线宽、字体、网格、坐标范围和单位更改仅重绘缓存。主窗 A→B→A 的灰显/恢复行为继续保留。

“幅度全范围”以当前频率显示范围内所有成功曲线共同确定上下限，保留最高峰并留 4% 顶部空间。截图和 300/400/600 DPI 导出包含所有曲线、图例、轴、网格及用户样式。
