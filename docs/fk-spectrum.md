# FK 谱

新增入口：**Tools → F-K Spectrum**。先在主窗口打开地震文件，再打开此窗口；窗口固定捕获打开时的文件路径，使用独立读文件对象，主窗口仍可操作。关闭主窗口时会取消计算并关闭 FK 窗口。

## 使用

1. 打开 FK 窗口时，首末道和时间窗默认取主窗口当前可见范围，随缩放、平移而变化，反向道排列也会转换为从小到大的文件道号；时间边界对齐可见范围内的实际样点，并限制在文件范围内。可继续手动修改。道号从 1 开始、包含两端，时间单位毫秒，从文件第 0 个采样点起算。使用连续等间距道；不要将不同炮集拼在一起解释为空间谱。
   该范围仅在新开 FK 窗口时捕获；激活已打开的 FK 窗口不会覆盖用户修改。计算仍使用原始数据，不套用主窗口滤波、AGC 或道头延迟校正。当前可见范围过窄或超过 800 万样点时，需手动调整范围或主窗口缩放后再计算。
2. 输入真实道间距 **dx（米）**。默认 12.5 m 只是初始值，不从 offset 字段推断。波数单位为 cycles/m，不是 rad/m。
3. 默认勾选去道均值、去时间均值、二维 Hann 窗；点击 Calculate。输入采用文件中的原始振幅，不套用主窗口的 AGC、滤波或显示增益。
4. 频率下限／上限、波数下限／上限、色标下限／上限均可自定义，点击 Apply range 应用，无需重算 FFT。重新计算会保留这些显示设置，不重置频率、波数和色标范围。切换幅度尺度也不会自动改动色标数值；如需自动调整，请点击 Auto color。上下限必须有序，坐标范围限制在实际 FFT 网格内；新数据使坐标范围越界时会限到可用边界，整个区间落在边界外时才恢复该坐标轴的可用全范围。
5. 可切换 Jet、Viridis、Inferno、Gray、RdBu。幅度显示可选 `log10(amplitude + 1e-12)` 或线性 FFT 幅度；色标数值使用当前显示尺度，不是 dB 或归一化百分比。Auto color 取当前显示范围中样点的 P1／P99.5，仅改变色标，不改变谱值。
6. 默认 Smooth (bilinear) 在当前显示幅度尺度中做双线性插值，再映射色标，减轻放大后的矩形色块；可切换 Original bins (nearest) 查看原始网格。插值只影响绘图，不改变 FFT 数值、频率或波数分辨率。
7. Image width / Height 分别控制图像宽高，可做宽图或窄图；宽度 640～4096 px，高度 280～4096 px。键盘输入合法尺寸即生效，也可点击 Apply size 明确应用。图像超过窗口时可滚动查看，外层窗口不会跟随变大。宽高会自动保存到当前用户的软件设置，下次打开 FK 窗口或重启软件后恢复。首次默认 1000×360 px。
8. Save PNG 保存完整图像、坐标、色标和文件／范围标题，默认当前目录浏览区文件夹，默认 `<原文件名去扩展名>-fk.png`。PNG 像素宽高严格采用上述输入值，不受显示器 DPI 倍率影响，也不会裁掉滚动区域外的内容。

## 界面参数说明

| 参数 | 作用 |
| --- | --- |
| 顶部文件路径 | 本次分析的原始地震文件，打开 FK 窗口时固定。 |
| First trace / Last trace | 参与 FFT 的连续道范围；从 1 编号，包含首末道。 |
| Start time / End time (ms) | 参与 FFT 的时间窗；相对文件第一个样点起算，不是道头的绝对时间。 |
| Trace spacing dx (m) | 相邻道的实际空间间距，决定波数坐标。请手动核实，默认值不代表读取了采集几何。 |
| Remove trace/sample means + 2-D Hann | 去除逐道均值、逐时间样点的跨道均值，再加二维 Hann 窗，减轻直流和边界泄漏；会改变谱幅度，也可能削弱各道共有的相干成分。 |
| Frequency min / max (Hz) | 图中频率纵轴范围，仅裁剪显示。 |
| Wavenumber min / max (cycles/m) | 图中波数横轴范围；正负号与 FFT 约定、道排列方向有关。 |
| Color min / max | 指定当前显示尺度的色标上下限。范围外的值使用色标两端颜色，不删除谱值。 |
| Jet / Viridis / Inferno / Gray / RdBu | 将幅度值映射为不同颜色，不改变数据。 |
| log10(amplitude + 1e-12) | 对数幅度显示，便于同时查看强弱能量；不是 dB。 |
| Linear amplitude | 未经对数变换的 FFT 幅度，强能量更突出；未按样点总数归一化。 |
| Apply range | 应用频率、波数和色标范围，不重算 FFT。 |
| Auto color (P1 / P99.5) | 用当前显示区域谱值的第 1 和第 99.5 百分位数自动设置色标范围，减少极端值对显示的影响。 |
| Smooth (bilinear) | 双线性显示插值，减轻色块；不提高真实频率或波数分辨率。 |
| Original bins (nearest) | 按 FFT 网格的最近邻显示，可看出实际采样网格，放大后出现色块是正常的。 |
| Image width / Height (px) | 包含坐标轴和色标的整张图片宽高；独立于外层窗口大小，自动记忆。 |
| Calculate / Cancel | 计算或取消；改变道范围、时间窗、dx、预处理选项后需要重新计算。 |
| Save PNG | 按设定宽高导出完整图片，包含滚动区域外的部分。 |
| df / dk | 计算完成后状态栏显示的频率和波数网格间隔；由数据范围、采样间隔及 dx 决定，不能靠加大图片或显示插值提高。 |

## 算法来源与数值约定

按照用户指定的 `桌面/latex/fk_spectrum_fixed.py` 中默认 Python 路线实现：

- 数据排列为 `[道, 时间采样点]`。
- 可选 `preprocess_gather`：先逐道去均值，再按每个时间样点去跨道均值，最后乘空间和时间 Hann 窗。
- 等价于 `fftshift(fft2(data))` 后取 `abs(...).T`，显示频率 `f >= 0` 的行。两个 FFT 方向均采用负指数，波数轴为移位后的 `fftfreq(nx, dx)`；不翻转波数正负。
- 不补零到不同的信号长度，不除以样点数；`df = 1/(nt*dt)`、`dk = 1/(nx*dx)`。与该脚本默认 Python 路线相同，偶数时间长度的 Nyquist 样点属于负频率端，因此正频率图不包含该点；最大频率略低于理论 Nyquist。
- 复用 `libCwp/pfafft.cpp` 的 float FFT。CWP 不直接支持的长度用 Bluestein 卷积并继续调用 CWP，保持参考脚本的频率／波数网格。与 NumPy 双精度结果存在 float 舍入差异。
- 本功能沿用默认 Python 路线，不实现脚本中的 MATLAB 兼容分支、跨文件 RMS 对齐、谱平滑或横条压制。
- 非有限输入会报错，避免静默更改原始数据。每次最多 800 万个道×时间样点，每轴最多 180180 点；二维 Hann 至少需要 3 道，禁用预处理后支持 2 道；时间窗至少 4 点。

默认自动色标对应脚本的每文件 P1/P99.5 处理，直接标注其实际 log10／线性值。原脚本默认映射后的 0～100% 色标与本功能默认显示颜色等价，刻度表达不同。

## 验证

`tests/fk_reference.json` 使用原脚本生成 5 组数值基准，涵盖奇／偶长度、CWP 非直接支持长度、开启／关闭预处理。`tests/generate_fk_reference.py` 可用该原脚本重新生成；JSON 记录来源文件名及 SHA256。Qt 回归逐点比较谱幅度，并核对全部频率／波数坐标。

回归还覆盖零输入、非法间距、NaN、取消、色标切换、手动范围校验和主窗口关闭。Windows x64 已构建和验证；Linux 使用同一套 Qt/CWP 源码，尚未实际编译运行。
