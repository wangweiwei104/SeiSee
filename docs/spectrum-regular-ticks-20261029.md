# 普通频谱规则刻度（2026-10-29，r6）

原先以显示范围除以固定等分数，导致 0–100 Hz 显示为 0、16.67、33.33…，幅度 0–71.69 显示为 0、11.95、23.90…。

现在从 `1、2、2.5、5 × 10ⁿ` 中选择接近适宜密度的间隔，将刻度对齐到该间隔的整数倍。例如：

- 频率 0–100 Hz：0、25、50、75、100。
- 频率 0–250 Hz：0、50、100、150、200、250。
- 幅度 0–71.69：0、10、20、30、40、50、60、70。
- dB 范围 −43–17：−40、−30、−20、−10、0、10。

刻度数量随绘图区和字号调整；小幅值使用相应的小数或科学计数法，避免标签重复、浮点尾数和负零。网格线与主刻度使用同一组坐标。

显示范围不因规则刻度改变：例如幅度上限仍为 71.69，而不是改成 70 或 80。视图端点如果不是规则倍数，不额外补一个不规则标签。计算数据、FFT 频点、250 Hz 理论边界和导出命名均保持原有语义；调整刻度、显示范围、字号和网格只重绘缓存。

实现：`SeiSeeMp/spectrumticks.h` 和 `FrequencyPlot::paintEvent()`；适用于单道、区域、多文件对比以及截图和高 DPI 导出。

验证入口为 `tools/build-fk.cmd`、`tools/test-fk.cmd`。新增用例覆盖规则数字、小数与负 dB、不同数量级、缩放偏移、无效范围、显示参数不触发 FFT；同时保留既有 19 项回归。
