# 速度曲线显示修复（2026-11-02）

已复现直线和双曲线均只显示两个点、没有预览线或确认曲线的情况。原因是 Auto 排列识别只检查道头是否变化：逐道编号的记录号，或所有道恒为 1 的 Channel，会把整个文件拆成单道排列。绘图代码在每个排列边界断开路径，因此只生成移动位置，无法形成线段；点标记仍能显示。

`VelocityGeometryWorker::run()` 现在要求自动候选同时存在边界与多道连续区间，优先使用有效的 Field record，再检查 Source point 和 Channel reset。没有有效候选时按 Single gather 显示。手动指定的 Gather by 规则保持原有语义。

直线和双曲线均已检查以下行为：第一点后移动鼠标显示虚线预览，继续移动会更新曲线；第二点确认后保留实线和两点标记。正常多排列边界仍不连接。前一版 FK 选框跨文件保留及参数同步也包含在本次运行包中。
