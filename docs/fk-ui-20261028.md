## 设置键

QSettings 组织/应用为 `WW` / `SeiSeeMp`（Windows 默认写入当前用户注册表，测试使用隔离 INI）。

- `FkSpectrum/display/initialized`
- `FkSpectrum/display/fkFmin`、`fkFmax`、`fkKmin`、`fkKmax`、`fkCmin`、`fkCmax`
- `FkSpectrum/advance/fkPalette`、`fkScale`、`fkInterpolation`
- 普通频谱使用相同子键，顶层组为 `FrequencySpectrum`。

参数变更仅刷新绘图。切换文件时不缩小输入控件的允许范围，避免小文件覆盖原参数；因此改选较小文件后，若保留的 Input Range 超出文件范围，需要点击对应 ALL 或手工调整，再计算。保留的 Display 范围若超出新谱的物理范围，越界部分显示为空白，不复制边缘频谱填充。

## 数值与缓存约定

- 道号从 1 开始、两端包含；时间单位 ms，相对原始文件样点 0，向内对齐实际采样点。
- 输入为文件原始振幅；不套用主窗的 AGC、归一化、滤波或道头延迟。主窗的显示设置不改变缓存来源的身份。均匀道间距 dx 默认 25 m，必须由用户确认；不从 offset 自动推断采集几何。
- FK 为未归一化 FFT 绝对幅值，波数单位 cycles/m；频率取非负半区，与 `numpy.fft.fftfreq(nt,dt) >= 0` 一致，因此偶数长度 Nyquist 不包含。未启用隐式去均值/Hann，避免 UI 中没有开关却改变输入幅值。
- Abs 是线性幅度，Log10 是 `log10(amplitude + 1e-12)`，不是 dB。FK 自动色标使用当前显示网格 P1/P99.5；普通频谱自动幅度范围保留峰值。插值仅影响图像。
- 一个窗口保留最后一次成功计算的谱；A → B → A 且未重算时恢复 A。若在 B 点击计算，成功后缓存替换为 B。缓存不写磁盘；关闭再打开同一窗口对象仍保留，退出程序后需要点击计算。
- 标题保留真正参与计算的文件、道/时间范围和 dx；底栏 Current File 指当前主窗数据，两者可能不同，灰色提示缓存来源不匹配。

## 附带修复

`MainWindow::FillDirGrid()` 定位目标文件后原本仍无条件选中首行（通常是 `..`），造成刚打开的地震图被 Clear。现在找到目标后直接返回，保持目标选中。选择目录等无数据项目时，频谱窗口来源设为空并灰显缓存。

本机依赖：Qt 5.15.2（`C:\ProgramData\anaconda3\Library`）、Visual Studio 2022 MSVC x64。普通 qmake 工程同样可编译新增源码；没有新增第三方依赖。

```powershell

```

验证产物与结果见 `build/fk-qa/`、`build/fk-qa-150/`。测试隔离用户设置，使用合成 SEG-Y 文件，不修改实际数据。

测试覆盖：独立直接 DFT 对照（包括奇数、质数长度）、一维频谱幅度、无效参数/NaN/取消、A/B/A 像素颜色恢复及无重复计算、计算中切换来源、Display/Advance 恢复、资源与按钮尺寸、矩形创建/调整/移动和导航锁定、主窗双入口、主窗真实数据切换、排队结果未处理时关闭、耗时 Toast、300 DPI 导出尺寸与元数据。

本次以 Windows x64 Release 编译；100% / 150% 的 Qt 离屏回归和图像检查用于验证布局、颜色和交互。未验证 Linux 编译、真实超大 SEG-Y、SU/CST 实测、多显示器切换或所有原生保存对话框。Qt 离屏插件不支持 raise 等能力的警告不表示原生窗口已验证；上游 Filt.svg 的解析警告不属于本次新增资源。

最终结果：100% 与 150% 各 **11 passed / 0 failed**（含初始化、清理）；将 PATH 限定为发布目录与 Windows 系统目录后，使用发布 DLL 运行同一回归也为 **11 passed / 0 failed**。完整应用 Release 编译成功，`git diff --check` 通过。

运行包：`dist/SeiSee-FK-20261028/SeiSeeMp.exe`，移动时保留整个目录。Qt/MSVC 依赖已随目录提供；发布 DLL 的离屏回归不等同于已完成所有原生窗口手工验收。编译入口仍为普通 `GxApps.pro`；本机辅助脚本中的 Qt/VS 路径可按其他机器调整。`tools/package-runtime.py` 用于补齐 Conda Qt 的非系统 DLL 依赖。
