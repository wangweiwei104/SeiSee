# 频谱界面修正 r7（2026-10-29，不含速度拾取）

应用代码基于 r6 提交 `095a6a5` 在独立目录修改，不含速度拾取；提交沿用上游最新主分支的文档、测试及工具清理结果。

1. **显示精度**：普通频谱与 FK 的 Frequency 显示 1 位小数，FK 的 Dx 显示 1 位，输入道号和时间显示整数，波数显示 3 位；坐标和状态栏同步使用相应精度。Amplitude/Color Range 保留原有精度。通过 `SpectrumSpinBox` 分离显示精度和实际数值，避免把 2001 μs 采样的 254.127 ms 末尾边界截成 254 ms 而丢失样点；FFT、Nyquist 和 CSV/图片命名中的实际计算数值保留。
2. **缺省模式**：新建普通频谱窗口始终选择 Single Trace，不再用旧 QSettings 中保存的 Selection 模式覆盖默认值。显示参数、曲线样式等设置照常恢复；同一窗口显式切换模式后，切换数据源不会重置模式。
3. **FK 自适应刻度**：普通频谱和 FK 复用 `spectrumAxisTicks`。根据数据范围、绘图区宽高、字号及相邻标签实际宽度选择规则间隔，横纵轴独立计算，避免固定五个标签。波数刻度最小分辨率为 0.001，频率为 0.1 Hz，避免重复标签和负零；缩放或调整字号只重绘缓存，不重新 FFT。色条刻度也按高度自动调整。
4. **框选滑块**：同时锁定主图外侧的横向/纵向联动滑块、内部滚动条和已有缩放/比例控件，适用于普通频谱和 FK。退出框选时按原先启用状态恢复；框选期间键盘操作不会移动滑块。
5. **色条标题**：移除 FK 色条上方的 `Amplitude`。Log10 时保留 `dB` 单位。普通频谱纵轴的 `Amplitude` / `Amplitude (dB)` 保持原有语义。

另保留目录扫描遇到被占用文件时的读句柄检查，防止 Windows CRT 因无效文件描述符终止程序；该修复不依赖速度拾取模块。
