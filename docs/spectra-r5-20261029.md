# FK / 普通频谱 r5（2026-10-29）

本轮按最新六项需求修改，基于此前已上传的 `46000a5`。下列行为取代 r4 文档中的“单道必须点击计算”、旧 Log10 数值和最后采样点坐标上限约定。

| 需求 | 更改细节 | 主要实现 |
| --- | --- | --- |
| 单道无需 RUN | 打开单道窗口、主窗有效选道、切回单道、编辑单道/时间参数或添加对比文件后自动计算。连续操作合并为 120 ms 的一次请求；计算中收到新选道也会计算最新请求。重复选择同一道、改变显示样式、关闭后重开相同缓存不重复 FFT。Selection 和 FK 继续由计算按钮启动。 | `FrequencySpectrumDialog::requestAutomatic()`、`runAutomatic()`、`setMainTrace()` |
| 频率、波数右边界 | 两模块的频率全范围使用 `1/(2*dt)`；FK 波数范围使用 `±1/(2*dx)`。2 ms 显示 250 Hz，25 m 显示 ±0.02 cycles/m。补回偶数时间长度的 Nyquist FFT 点；保留实际 `df`、`dk` 和 FFT 点坐标，不拉伸数据凑边界。FK 波数边缘按周期插值。识别旧版完整范围并迁移，主动设定的裁剪范围保留。 | `fktransform.*`、`FkPlot`、`FrequencyPlot`、全范围按钮 |
| Amplitude / dB | 普通频谱纵轴为 `Amplitude`，Log10 时为 `Amplitude (dB)`。为使 dB 标识有数学意义，两模块统一采用 `20*log10(max(amplitude,1e-12))`，参考幅度为 1，零幅度下限为 −240 dB；不是相对峰值归一化。切换单位只使用缓存重绘，幅度/色标自动适配；旧 Log10 显示范围乘 20 迁移。FK 纵轴仍为 Frequency，色标标明 Amplitude / dB。 | `spectrumAmplitudeValue()`、两模块的显示/设置代码 |
| 导出命名 | 复用主窗的目录与命名规则：保存在谱对应源文件旁，以文件基础名、实际计算道范围、实际时间范围（秒）、谱类型/单位/显示范围组成名称；高清导出附 DPI，同名依次追加 `_1`、`_2`。输入改变或切换来源后导出缓存，仍使用缓存的真实来源和范围。结果通过 Toast 显示路径。 | `SpectrumDialog::setCaptureRange()`、`nextImagePath()`、两模块 `exportImage()` |
| 图注右上角 | 主文件及各对比曲线的线型样本、文件名排在绘图区内部右上角，白色半透明底衬；颜色、线宽沿用各文件设置。长文件名中间省略，完整路径可从 Comparison 控件查看。 | `FrequencyPlot::paintEvent()` |
| 框选前黑色光标 | 新增透明背景、纯黑笔画的 `SelectionBlackCurs.xpm`。用于两子窗口的框选放大，以及其触发的主图输入范围框选；保留原蓝边半透明矩形和交互。 | `myrc.qrc`、两绘图控件、`MyScrollArea::setSelectionMode()` |

高清导出同步主窗 View → Export image DPI 的 300 / 400 / 600 DPI 设置。同时修复该菜单的既有数值绑定问题：`QAction::data()` 必须通过 `setData()` 设置，Designer 动态属性不能代替该接口。

奇数长度 FFT 没有恰好落在 Nyquist 的采样点：坐标仍显示理论上限，折线结束于真实的最后频点；FK 栅格的剩余半个频率网格沿用边缘值。没有补造 Nyquist 频谱值。

## 验证

Windows x64 Release 构建入口为 `tools/build-fk.cmd`，回归入口为 `tools/test-fk.cmd`。测试使用合成 SEG-Y 和隔离的 INI 设置，不改动真实数据。覆盖直接 DFT 对照、奇偶长度和 Nyquist 能量、dB 换算、自动选道与忙碌时更新、区域手动计算、缓存重开、多文件对比、设置恢复、关闭/取消、图片命名与防覆盖、PNG DPI、选框初始隐藏及光标像素颜色。

100% / 150% 离屏回归各 **19 passed / 0 failed**（包含初始化、清理）。图像检查包含普通频谱右上角多文件图例、Amplitude / dB 标签、FK 波数边界和框选外观。隔离开发环境 PATH 的运行依赖回归同样 **19 passed / 0 failed**。本地运行包：`dist/SeiSee-Spectra-20261029-r5/SeiSeeMp.exe`，移动时须保留整个目录。验证结果位于 `build/fk-qa`、`build/spectra-r5-qa-150`、`build/spectra-r5-portable-qa/results`。

未实测 Linux、多显示器切换或真实超大 SEG-Y 的性能。
