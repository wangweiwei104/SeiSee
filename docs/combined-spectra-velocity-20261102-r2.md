# 频谱与速度拾取合并版 r2（2026-11-02）

本版合并频谱框选、FK 框选与速度拾取的最新修改。

## 频谱与 FK 框选

- 在区域框选模式中切换主窗口文件，按相同道号和时间范围保留选框。新文件较小时只显示重叠部分，原参数不变；完全不重叠时暂时隐藏，切回后恢复。
- 修改起止道号或起止时间，按 Enter 或移开输入焦点确认，主图选框同步改变；拖动选框仍会反向更新参数。
- 频谱窗口切回单道模式、取消框选或关闭窗口会清除选框。频谱与 FK 的选框拥有各自的输入范围，只有当前开启框选的窗口能控制主图选框。
- 区域模式仍需点击 Calculate；单道频谱保留跟随主图选道和自动计算。

两类频谱窗口通过 `SpectrumDialog::inputRange()` 和 `inputRangeChanged()` 共用选区显示逻辑，避免程序更新选框时将像素取整误差反复写回输入参数。

## 速度拾取

- 保留直线/双曲线预览线及确认线缺失的修复；自动分组忽略会把全部道拆成单道排列的道头候选。
- 关闭速度窗口后，主图速度线隐藏、拾取停止，记录保留。重新打开会自动显示本次程序会话内当前文件已绘制的速度线；文件之间的缓存互相独立。退出程序前仍需 Export CSV，重启后可 Import CSV。
- 在列表中选中某条记录，主图对应曲线以橙色描边并临时加粗，且绘制在其他曲线上方。选中其他记录时高亮切换；排序后仍按记录 id 对应。记录本身的颜色与线宽不被高亮改写。
- 速度拾取与频谱/FK 框选互斥。关闭速度窗口时，主图截图和图片导出也不再叠加速度线。

## 验证

Windows x64 Release / Qt 5.15.2 / MSVC 2022 完整应用构建通过。100% 和 150% 缩放下，FK/频谱回归各 23 项通过，速度回归各 21 项通过，均为 0 失败（含初始化、清理）。

覆盖两类框选的四参数键盘输入、不同文件范围和采样间隔、切回恢复、鼠标移动、切回单道模式；速度真实鼠标预览、确认线、两类框选互斥、关闭隐藏与重开恢复、切换列表选择与排序后的高亮、CSV 和截图/300 DPI 导出对齐。已查看频谱选框及速度关闭、重开、选中不同曲线的离屏截图。验证使用合成 SEG-Y，未进行真实超大文件或多显示器手工验收。
